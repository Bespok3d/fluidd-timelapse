# Attributions - timelapse

**Plugin author:** paxx12 (Extended Firmware overlay `33-feature-timelapse-stub`), packaged by Bespok3d

Turns on the Timelapse menu in Fluidd and Mainsail.

| --- | --- | --- | --- | --- |

The Moonraker component in this package, `moonraker/timelapse.py`, is the file from the Extended Firmware overlay
`33-feature-timelapse-stub` (paxx12), GPL-3.0. It ships here unchanged, byte for byte. Timelapse
recovery work in that firmware is credited to @horzadome.

The widely used `moonraker-timelapse` component (mainsail-crew, GPL-3.0) is a different project and
none of its code is used here.
